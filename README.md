# Nicolás Racca · Presentation Page

Sitio web personal de presentación de Nicolás Racca — Full Stack Developer y estudiante de Ingeniería Informática. Incluye secciones de presentación, experiencia, proyectos, conocimientos, certificaciones y contacto.

## Estructura del proyecto

```
├── index.html      # Página principal
├── css/main.css    # Estilos
```

## Uso local

Al ser un sitio estático, alcanza con abrir `index.html` en el navegador, o servirlo localmente:

```bash
npx serve .
```
